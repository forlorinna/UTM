这次交付是可运行的校园街区样板。建筑连续性、真实场地精度与画面仍未达到 MASTER 的全校照片级验收门槛。

## 运行验证

- Godot 4.7.2 源工程做独立导入与 headless 自动测试。覆盖角色地面碰撞、走跑动画、飞行、20/50/150/300 米高度的 LOD 选择、四个地标的材质和碰撞、驾驶和车轮、暴雨/湿润、阅览室、跨午夜时钟、存档和三语资源。
- 使用 Linux 桌面软件渲染检查实际帧，包含 Compatibility/OpenGL llvmpipe 与 Mobile/Vulkan llvmpipe。桌面窗口截图来自游戏的 Viewport。测试图的飞行和照片视角由命令行指定相机。
- ARM64 APK 经 apksigner、aapt2、16 KB 对齐与 ZIP 结构校验。包名 com.forlorinna.utmklcampuslife，最低 API 24，目标 API 36，版本 0.1.0，code 1，横屏，无 INTERNET 权限。附带的是独立调试签名构建。
- 无连接的 Android 设备和 KVM 模拟器，故真机安装、GPU 功能、触控、耗电、温度、20 分钟连续运行、真机帧率和 1% low 均待测。桌面 Vulkan 测试仅用于判断渲染路径实际启动并出图。
- 四座地标及道具均以公开资料和独立造型进行近似。地块局部地面、摆件、灯位与路宽未实测，城市远景未完成。街景使用真实扫描树与公开授权模型，地标建筑采用参考建模。
- 室内当前是可进出的虚构阅览室。人流由五条短路线、时段、天气和密度设置控制。导航网格避障、完整课表与任务、交通车流、课程和食堂场景、其余公共室内和精细动画状态仍未完成。
