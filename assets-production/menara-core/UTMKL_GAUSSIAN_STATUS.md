# UTMKL Gaussian Splatting 数据状态

**当前没有已核实、可在本项目内再分发的 UTMKL 或 Menara Razak 实景 Gaussian Splatting 数据。** 本轮检索关键词包括 UTMKL、Menara Razak、Kuala Lumpur、PLY、SPZ、Gaussian Splatting、摄影测量和 LiDAR，并检索公开数据仓库及大学导览。大学页面提供地图、照片和虚拟导览，这些页面未提供可再分发的高斯模型文件。 [UTM 校园虚拟导览](https://kl.utm.my/project/campus-map-virtual-tour/) · [校方照片与视频](https://kl.utm.my/project/explore-in-pictures-and-videos/) · [校园实地走访](https://dvcdev.utm.my/kl/walkabout-kampus/)

状态保持为 **技术已验证，等待本地授权数据**。原项目已有 Spark 管线。上一阶段下载、裁切并实际渲染了 Necessity Robotics 在印度公园采集的 122,490 个高斯，也验证过 Marcel Padilla 的独立室内植物样本。它们是独立测试记录。本次核心区以 Menara Razak 网格和现场环境网格渲染，场景资源清单中没有高斯资产。 [上阶段测试成图](https://github.com/forlorinna/UTM/blob/d0c8f17b4aa645a2d1c8220d3db11b1183e7a864/assets-production/menara-razak/renders/04_Independent_Gaussian_India.png) · [印度公园原始数据与许可](https://necessityrobotics.github.io/explore.html?map=oak_160543)
